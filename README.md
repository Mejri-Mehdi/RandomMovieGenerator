# 🎬 Random Movie Generator

A very simple and basic web application that generates a random movie suggestion with the click of a button. Built using plain HTML, CSS, and JavaScript.

## 📌 Features
- Randomly selects a movie from a predefined list
- One-click generation
- Beginner-friendly JavaScript logic
- No external libraries or frameworks

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript (Vanilla)

## 🚀 How It Works
1. A list of movies is stored in a JavaScript array.
2. When the user clicks the button, a random index is generated.
3. The movie at that index is displayed on the screen.

## 📂 Project Structure

├── index.html
├── style.css
└── script.js


## ▶️ How to Run
1. Download or clone the repository: https://github.com/Mejri-Mehdi/RandomMovieGenerator


2. Open `index.html` in your web browser.
3. Click the button to get a random movie suggestion 🎥
