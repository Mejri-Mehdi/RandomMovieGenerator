| Technology | Role |

| **HTML** | Page structure and content |
| **CSS** | Styling and visual presentation |
| **JavaScript (Vanilla)** | Core logic – random generation & DOM updates |

The entire application runs completely in the browser – no server, no build step.

---

## 🚀 How It Works

1. A list of popular movies is stored in a JavaScript array.
2. When the user clicks the **“Generate Movie”** button, a random index is calculated.
3. The movie title at that index is instantly displayed on the screen.

It’s a perfect introduction to:
- `Math.random()` and `Math.floor()`  
- DOM manipulation with `document.getElementById()`  
- Event handling with `addEventListener()`
